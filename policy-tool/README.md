# Policy tool: every flood alert names a shelter

Interactive proof of concept for Anna, a cross-border crisis coordinator. It replays the July 2021 Ahr flood (EMS AOI `de_15`, Bad Neuenahr-Ahrweiler) along the warning chain Detect → Interpret → Decide → Alert → Johan, and matches every home in the mapped flood to the nearest safe shelter that still has room.

## Open it

```powershell
python -m http.server 8765 --directory policy-tool
```

Then open <http://localhost:8765>. Use ← / → to move through the five steps; click any home to see its alert; the sliders below the map re-run the matching. Opening `index.html` directly from disk may block the data file in some browsers.

For submission, build one self-contained page (data inlined; Leaflet and map tiles still need internet):

```powershell
python scripts/bundle_policy_tool.py
```

This writes `deliverables/shelter-alert-tool.html`.

## Data and method

`data/de_15.js` is generated by `python scripts/build_shelter_alert_data.py --aoi de_15`, which also writes `data-analysis/shelter_alert_de_15_summary.json` and `..._shelters.csv`.

| Input | Use |
|---|---|
| `data/reference/aoi_event_unions.parquet` (EMS EMSR517) | Mapped 2021 flood (water + flood traces) |
| GHS-OBAT R2024A DEU | Residential points inside the flood; footprint and height of shelter buildings |
| GHS-POP R2023A E2020 30″ | Residents per cell, shared among residential buildings by floor area |
| EFAS RP100 / RP500 depth | Coverage check of homes; shelters with RP500 depth can be excluded |
| OpenStreetMap via Overpass (cached in `data/raw/osm/`) | Schools, sports halls, community buildings, care sites, village names |

Checks run by the build script: homes in the flood (6,975), homes with RP500 depth (3,345) and RP100 depth (2,968) must equal `data/reference/aoi_metrics.csv`; the build stops otherwise. The page recomputes the matching in the browser; at the default plan it reproduces the summary JSON (11,124 placed, 9,770.8 unplaced residents).

Default plan: 3.5 m² per person, 50 % of floor area usable, storeys = height ÷ 3 m, shelters more than 50 m from the 2021 flood and without RP500 depth, nearest-shelter-with-room-first matching on straight-line distance up to 5 km. Limits are listed at the bottom of the page.
