# Four independent idea lanes

Assign one coder and one branch to each lane. These are working areas, not predetermined conclusions. Each lane README should hold a question, proposed source files, a small result-table plan, validation, and figure plan. A lane may be changed when the challenge question is released.

| Lane | Initial focus | Primary handoff |
|---|---|---|
| `01-observed-flood/` | EMS event definition and source dates | Event geometry and observation notes |
| `02-hazard-overlap/` | EFAS comparison with event evidence | Denominator-safe overlap table |
| `03-building-exposure/` | OBAT point exposure and grades | Building/asset table with source checks |
| `04-population/` | GHS-POP cell allocation | Population estimate and sensitivity table |

Use `data-analysis/FINDING_TEMPLATE.md` for a result that the team may cite. Put figures in `figures/generated/` with filenames that include the lane or question. Ask another coder to review the source record and label before a figure is used in a deliverable.
